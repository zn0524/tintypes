# tintypes

Tintypes is an app designed to detect AI-generated images and text. The name draws inspiration from an early photographic process that created a direct positive of an image, requiring no transfer. The app features a descriptive user interface, large font, high contrasting text, and floating buttons to accommodate senior citizens. Running in the background are two AI detectors, one for images and another for text, with a combined download size of 300 megabytes, allowing them to operate comfortably within mobile constraints. Both models are custom fine-tuned, a process of taking a generalized AI detector and feeding in training data, specific to the task, so it learns the exact patterns needed for the detector. Alongside the two accessible models, the app has a how it works page, detailing how to properly use the apps for the most accurate results.
